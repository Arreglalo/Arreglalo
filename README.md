# 🛠️ Radar de Servicios domésticos

Radar de Servicios es una plataforma que conecta a personas con problemas técnicos en el hogar con profesionales locales mediante geolocalización en tiempo real.

## 🚀 ¿Cómo funciona?

### Para Clientes (Hogares)
1. **Reporte:** Subís una foto y descripción de la urgencia (plomería, gas, luz).
2. **Mapa:** Tu pedido aparece en el "Radar" para profesionales cercanos.
3. **Selección:** Revisás postulaciones, elegís al experto y chateás para coordinar.

### Para Profesionales (Expertos)
1. **Mapa de Ofertas:** Visualizás trabajos activos en tu barrio vía Google Maps.
2. **Postulación:** Te postulás a las ofertas que te interesan.
3. **Conexión:** Una vez aceptado por el cliente, habilitás un chat exclusivo para cerrar el trato.

## 💳 Modelo de Negocio (Profesionales)
Solo pagás por la vinculación efectiva con el cliente:
- **Bienvenida:** 3 vinculaciones 100% bonificadas.
- **Planes:** 1 vinculación, pack de 5 vinculaciones o abono mensual ilimitado.
- **Pagos:** Integración total con **Mercado Pago** (moneda local).

## 🛠️ Stack Tecnológico
- **Mapas:** Google Maps API.
- **Pagos:** SDK de Mercado Pago.
- **Chat:**  Utilizamos un chat privado y exclusivo entre el cliente y profesional.

## 🛡️ Seguridad y Comunidad
Para garantizar una experiencia confiable y segura, la plataforma incluye un **Sistema de Reportes** activo para ambas partes:

*   **Reporte de Contenido:** Tanto clientes como profesionales pueden denunciar publicaciones inapropiadas, fotos falsas o descripciones engañosas.
*   **Protección del Usuario:** Si detectás comportamientos sospechosos o faltas a los términos de uso durante el chat o el servicio, podés emitir un reporte inmediato.
*   **Moderación Activa:** Nuestro equipo revisa cada caso para mantener la integridad de la comunidad y sancionar cuentas que no cumplan con las normas de convivencia.
